# Development

## Sobre esta Seção

A seção **Development** reúne os padrões, práticas e diretrizes utilizados durante o desenvolvimento do ecossistema CarneCerta.

Seu objetivo é promover consistência entre os módulos, facilitar a colaboração entre desenvolvedores e manter a qualidade do código ao longo da evolução do projeto.

---

# Objetivos

Esta seção tem como objetivos:

- definir padrões de desenvolvimento;
- documentar o fluxo de trabalho com Git;
- estabelecer a estratégia de branches;
- padronizar a organização dos projetos;
- registrar boas práticas de desenvolvimento.

# Organização

Os documentos desta seção descrevem como o código deve ser desenvolvido, organizado, versionado e mantido, garantindo consistência entre todos os módulos do ecossistema.
