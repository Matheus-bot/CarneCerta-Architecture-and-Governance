# Glossary

## Introdução

Este glossário reúne os principais termos, siglas e conceitos utilizados na documentação do ecossistema **CarneCerta**.

Seu objetivo é padronizar a terminologia adotada ao longo do projeto, facilitando a compreensão da documentação por desenvolvedores, colaboradores e demais interessados.

---

# Termos Gerais

| Termo | Definição |
|--------|-----------|
| Ecossistema | Conjunto de módulos e soluções que compõem o projeto CarneCerta. |
| Módulo | Unidade funcional independente que integra o ecossistema CarneCerta. |
| Stakeholder | Pessoa, organização ou sistema que possui interesse direto ou indireto no projeto. |
| Arquitetura de Software | Estrutura que define os componentes do sistema e a forma como eles se relacionam. |
| Governança | Conjunto de práticas, padrões e processos que orientam a evolução do projeto. |

---

# Arquitetura

| Termo | Definição |
|--------|-----------|
| ADR (Architecture Decision Record) | Documento utilizado para registrar decisões arquiteturais importantes. |
| Diagrama de Arquitetura | Representação visual da estrutura e dos componentes do sistema. |
| Integração | Comunicação entre módulos ou sistemas distintos. |
| Escalabilidade | Capacidade do sistema de crescer sem comprometer seu desempenho ou arquitetura. |
| Modularidade | Organização do sistema em componentes independentes e reutilizáveis. |

---

# Dados e Analytics

| Termo | Definição |
|--------|-----------|
| Data Warehouse | Base de dados voltada para análise e apoio à tomada de decisão. |
| ETL | Processo de Extração, Transformação e Carga de dados. |
| Star Schema | Modelo dimensional composto por tabelas fato e dimensões. |
| Dashboard | Painel visual utilizado para apresentar indicadores e métricas. |
| KPI (Key Performance Indicator) | Indicador utilizado para medir o desempenho de processos ou objetivos. |

---

# Desenvolvimento

| Termo | Definição |
|--------|-----------|
| CI/CD | Práticas de Integração Contínua e Entrega/Implantação Contínua. |
| Git Workflow | Estratégia de organização do trabalho utilizando Git. |
| Branch | Linha independente de desenvolvimento dentro do repositório Git. |
| Commit | Registro de alterações realizadas no controle de versão. |
| Pull Request | Solicitação para integrar alterações entre branches do repositório. |

---

# Acessibilidade

| Termo | Definição |
|--------|-----------|
| Acessibilidade Digital | Práticas que tornam sistemas utilizáveis por pessoas com diferentes necessidades e habilidades. |
| Libras | Língua Brasileira de Sinais, reconhecida oficialmente como meio legal de comunicação e expressão no Brasil. |
| Tradutor para Libras | Recurso de acessibilidade que traduz conteúdos da interface para Libras, apoiando a comunicação com pessoas surdas. |
| WCAG (Web Content Accessibility Guidelines) | Diretrizes internacionais para desenvolvimento de conteúdo web acessível. |
| Tecnologia Assistiva | Recursos, dispositivos ou softwares que promovem autonomia e inclusão de pessoas com deficiência. |

---

# Tecnologias do Projeto

| Termo | Definição |
|--------|-----------|
| SQL Server | Sistema Gerenciador de Banco de Dados utilizado pelo projeto. |
| Power BI | Plataforma utilizada para criação de dashboards e análises de dados. |
| IoT (Internet of Things) | Conjunto de dispositivos conectados capazes de coletar e compartilhar informações. |
| Firebase | Plataforma utilizada para suporte a funcionalidades do módulo Mobile. |
| Mermaid | Ferramenta utilizada para criação de diagramas em Markdown. |
