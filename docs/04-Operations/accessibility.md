# Accessibility

## Objetivo

Este documento define as diretrizes de acessibilidade adotadas pelo ecossistema CarneCerta.

A acessibilidade é considerada um requisito não funcional do projeto e deve estar presente desde o planejamento até a entrega das aplicações, garantindo uma experiência inclusiva para todos os usuários.

---

# Compromisso

O CarneCerta tem como compromisso desenvolver soluções acessíveis, promovendo autonomia, inclusão digital e igualdade de acesso às suas funcionalidades.

A acessibilidade deve ser considerada em todos os módulos do ecossistema.

---

# Princípios

As aplicações deverão seguir os seguintes princípios:

- percepção;
- operabilidade;
- compreensão;
- robustez.

Esses princípios são baseados nas recomendações internacionais de acessibilidade para aplicações Web.

---

# Diretrizes Gerais

Sempre que aplicável, as aplicações deverão:

- utilizar HTML semântico;
- permitir navegação por teclado;
- possuir contraste adequado entre cores;
- utilizar textos alternativos para imagens;
- manter estrutura consistente entre as páginas;
- utilizar títulos e hierarquia de conteúdo adequados;
- fornecer mensagens claras para erros e validações.

---

# Inclusão da Comunidade Surda

Um dos principais objetivos do CarneCerta é tornar a experiência de compra mais acessível para pessoas surdas.

Para isso, a plataforma Web poderá disponibilizar recursos de tradução para Libras, permitindo maior autonomia durante a navegação e utilização do sistema.

Esse recurso deverá estar disponível de forma simples e visível para o usuário.

---

# Compatibilidade

Sempre que possível, as aplicações deverão ser compatíveis com:

- leitores de tela;
- navegação exclusivamente por teclado;
- diferentes tamanhos de tela;
- dispositivos móveis;
- tecnologias assistivas.

---

# Testes de Acessibilidade

Durante o desenvolvimento, recomenda-se realizar verificações relacionadas a:

- navegação por teclado;
- contraste de cores;
- estrutura semântica;
- textos alternativos;
- funcionamento do recurso de tradução para Libras;
- responsividade das interfaces.

---

# Evolução Contínua

As práticas de acessibilidade deverão evoluir continuamente, acompanhando novas recomendações técnicas, necessidades dos usuários e melhorias incorporadas ao ecossistema CarneCerta.
