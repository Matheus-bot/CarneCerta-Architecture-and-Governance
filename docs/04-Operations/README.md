# Operations

## Sobre esta Seção

A seção **Operations** reúne as práticas operacionais adotadas no ecossistema CarneCerta para garantir qualidade, segurança, confiabilidade e disponibilidade das aplicações.

Além dos aspectos técnicos de operação, esta seção documenta as diretrizes relacionadas à acessibilidade, um dos princípios fundamentais do projeto.

---

# Objetivos

Esta seção tem como objetivos:

- definir diretrizes de segurança;
- estabelecer estratégias de testes;
- documentar o processo de Integração Contínua e Entrega Contínua (CI/CD);
- registrar o processo de deploy;
- definir práticas de monitoramento;
- documentar os requisitos de acessibilidade.

# Princípios

As práticas operacionais do CarneCerta são baseadas nos seguintes princípios:

- segurança desde o desenvolvimento;
- qualidade contínua;
- automação;
- monitoramento;
- disponibilidade;
- acessibilidade por padrão.

---

# Relação com a Arquitetura

As decisões descritas nesta seção complementam os princípios definidos na arquitetura do projeto, especialmente:

- ADR-005 — Accessibility by Design;
- ADR-006 — Git Workflow e Estratégia de Branches;
- ADR-007 — Padronização da Documentação Técnica.
